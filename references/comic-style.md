# 金融学习手绘漫画：内容、角色、道具与场景统一

## 用户的视觉偏好

参考用户给出的 Nicky Case 互动漫画截图（https://ncase.me/remember/zh.html）的简洁手绘、多人对话、具体环境、平涂背景、气泡和分镜节奏。当前目标是“内容设计 + 好看的原创手绘漫画”，不要求复刻网站的滚动网页或复杂互动。用户以《海绵宝宝》的比奇堡举例，强调一个世界里有不同人物、场所和关系，但使用金融学习原创角色，不使用影视角色。

默认采用有连续性的金融情境世界。人物、道具和场景必须帮助解释知识，不使用“同一个小人站在空白背景前，旁边几张说明牌”的模板。不要只替换对白、表情和背景色；至少改变一个有教学意义的动作、道具关系或场景层次。

## 金融学习漫画资产库

当任务需要生成或扩展角色、表情、服装、道具或场景图片时，同时使用 `finance-comic-imagegen` skill，并按其 `references/prompt-templates.md` 选择提示词模板。本文件负责金融教学分镜和内容取舍，`finance-comic-imagegen` 负责统一的生图风格、素材连续性和透明背景要求。

金融主题默认使用 `finance-learning` 的原创角色资产：

- `finance-comic-character-bible.png`：小禾、阿海、老钟的身份、主色和基础道具。
- `finance-comic-expression-action-sheet.png`：三位主角的表情和动作。
- `finance-comic-costume-prop-sheet.png`：按场景切换服装与金融道具，同时保留角色识别特征。
- `finance-comic-scene-palette-sheet.png`：交易大厅、订单柜台、交易日历、撮合大厅、价格背板、复习教室、盘后窗口和风险提示场景。
- `finance-comic-outdoor-scene-sheet.png`：证券街入口、新闻广场、风险十字路口、长期投资公园、市场波动海边和财报咖啡馆等户外场景。
- `finance-comic-technical-prop-sheet.png`：技术分析、量化、组合、风险、财报、估值、衍生品和金融 NLP 的专业道具；默认以透明背景叠加到漫画场景中。

- `finance-comic-supporting-expression-action-prop-sheet.png`：五位配角各自对应的表情、动作和金融道具。

使用这些资产时，保持人物的脸型、发型、线稿粗细和主色连续。配角只在其行为能解释知识时出现；不要为了画面热闹让所有角色同框。服装和道具可以随场景变化，但必须服务于学习目标。

角色表和道具表若显示黑色或棋盘格，通常代表透明区域的查看器预览，不是实际背景。输出 PNG 素材时优先保留 alpha 透明通道；需要场景背景时，再把素材叠加到指定的室内或户外配色上。

## 生图调用规则

- 生成角色设定、动作表、服装表、道具表或场景表时，先读取 `finance-comic-imagegen/SKILL.md`。
- 生成透明角色或道具时必须要求 alpha 透明背景，不把黑色或棋盘格烘焙进图片。
- 生成完整漫画场景时使用室内或户外场景配色，并保留人物可站立、对话和放置道具的空间。
- 参考图用于保持原创角色的连续性；不要把整张参考图直接复制成新画面，也不要混用风格差异很大的素材库。

## 先把知识变成场景

制作前在分镜中写清每格的：学习目标、认知重点、场所、出场角色及其关系、动作前后状态、关键道具或数据、景别、背景色意图、用户交互。简单短课可用几行计划，不需要为此增加问卷或审批。

按当前主题选一个能贯穿的世界，例如海边小镇、餐馆公司、交易集市、银行街区。首次使用时用一两句介绍角色职责；同一课程的角色身份、服装和场所标志保持一致。不要每次重新定义角色，也不要强行沿用不适合新知识的旧场景。

- 股权与分红：餐馆经营现场、股东会议、收银台；经营者、股东员工、其他投资者。
- 交易规则与撮合：交易柜台、订单队列、报价屏、日历街道；买方、卖方、工作人员。
- 利息与贷款：银行柜台、借款人店铺、还款日历；存款人、借款人、银行工作人员。
- 风险与分散：不同生意的店铺和资产篮子；经营者、投资者，风险通过具体事件表现。



## 按教学重点安排画面

- 核心机制或易错点：用具体环境和相关角色互动，多给一次动作变化或一个对比镜头。
- 配角用于提出不同问题或承担交易另一方，不为了人数凑角色。短课通常2–4个有明确职责的角色足够，不要求每格全部出场。
- 计算与数据：切到股票、现金、账本、日历或价格牌的特写，允许完全没有人物。
- 定义与总结：可用干净的背板、简短示意或对照；减少角色与环境细节。
- 转场：用门牌、地点、时钟或天色变化帮助用户判断“到了哪里、过了多久”，不只换背景颜色。
- 景别随内容变化：环境全景建立场所，中景呈现对话，近景展示机制。不要所有页面重复同一个左右排版，也不规定机械的镜头比例。

## 人物动作与环境

保持手绘粗线条、圆角、小幅不规则曲线，避免逐帧随机抖动。人物有稳定辨识特征，但动作需随事件改变：走入柜台、递出订单、接过股票、转身对话、坐下开会、移动资金或比较账本。不能只动嘴、抬同一只手或切换表情。

动作要有明确起因和结果。例如订单从买家手中进入队列，再与卖单配对；未成交时保留在队列，而不是凭空消失。现金、股数和所有权变化要能跟踪，人物视线和指向应对应关键道具。

环境只保留能识别地点和帮助理解的元素：餐馆可用招牌、桌椅和收银台；交易所可用柜台、报价屏和队列；银行可用窗口、存折和日历。背景与前景分层，避免无关细节争抢注意力。

## 背景与色彩

允许每种场所拥有不同的场景底色、墙面、地面和背板，例如蓝紫交易大厅、暖沙色餐馆、薄荷色银行；同一场所保持一致，重要数值的颜色语义跨场景稳定。不是每格随机换色，也不是把红色都解释成下跌。

用户明确希望有彩色场景和背板。它们应作为漫画场景的组成部分绘制，不是套一层产品卡片边框。使用平涂色、深色轮廓和对比清楚的气泡，避免装饰性阴影与渐变。对话外层保持透明，场景内部可有地板、墙面、天空等色块；主题受限时使用相应主题色，保持文本对比度。

## 对白、节奏与互动

每格只承担一个主要认识。短对白放气泡，尾巴明确指向说话人；旁白、条件、公式和对白区分。中文采用清晰字体，不能靠缩小字号塞进气泡。对话多时拆成多个镜头，而不是铺满段落。

使用“事件或误解 → 预测 → 动作验证 → 原因 → 记忆提示”的节奏，允许跳过不必要步骤。漫画可以是静态分镜、轻微动效或视频；默认优先保证画面和知识清晰，不为了动画而加入复杂交互。若制作轻动画，动作应有起因和结果，不强制自动播放，不持续循环。

## A股基础课的可用分镜示例

1. 周五交易柜台：新投资者递出100股买单，卖方在另一侧，工作人员接单；明确是假设原来没有持仓。
2. 午后同一柜台：投资者想卖刚买的股票，工作人员说明T+1；股票仍在持仓处。
3. 无人物日历特写：周五翻过周末，到下个交易日；假设无节假日与停牌，不暗示“24小时后”。
4. 订单打包台：一组100股、两组200股，另一侧标出不足100股的卖出余额；数量规则限定板块。
5. 撮合大厅：买卖双方订单按价格与时间排队，匹配后交换，剩余订单继续等待。
6. 无人物价格背板：正常交易日10元前收盘与对应涨跌停价，注明板块及例外。
7. 夜色或时钟切换到盘后窗口：只在查证适用规则后展示固定价格成交，不能沿用过时规则。

这只是情境示例，不是已经完成的动画。具体规则每次查证，不能把分镜示例当作行情或监管资料。

## 工具选择

生图素材：需要角色、表情、服装、道具或场景图片时，使用 `finance-comic-imagegen` skill，并读取其 `references/prompt-templates.md`。优先使用透明 PNG 角色和道具，再叠加到指定的室内或户外场景。保持角色脸型、发型、线稿和主色连续。

漫画成稿：优先使用图片分镜、图文长页或简单排版；用户明确要求对话内互动时再加载 visualize。已有图形可复用，但布局和动作应按镜头改变，不要为了适配工具而退回空白单人模板。

动画视频：用户明确要求 MP4 时才使用 ManimCE；把已有角色和道具作为素材叠加到可控的分镜动作中。只说“漫画”或“讲解图”时，不默认制作视频。

明确要MP4时使用ManimCE，并加载相关动画技能。需复杂场景素材时可采用图像工具，再添加可控动作；简单线条场景优先矢量，避免无必要依赖。角色和环境的复用不等于复用整张画面。

## 交付前检查

检查完整场景序列而非只截一格：
- 每格都能说清为什么选择这个地点、这些角色和这个景别。
- 重要机制有动作或图示验证，辅助信息不抢戏；无人镜头出现得有理由。
- 多个相关场景在构图、背景环境和动作上有可辨别差异，转场有线索。
- 角色关系、股数、现金和时间前后一致，没有金融类比错误。
- 气泡不压脸或关键数据，窄屏可读；按钮与预测揭晓顺序正确。
- 实测有代表性的多人场景、道具特写和不同底色场景，并检查动画前后状态。不能只以文件存在或格式校验代替视觉验收。
